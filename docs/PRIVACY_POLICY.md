# プライバシーポリシー（Codex Blanche Android）

**日本語** | [English](PRIVACY_POLICY.en.md)

**最終更新日: 2026年5月7日**

本プライバシーポリシー（以下「本ポリシー」）は、モバイルアプリケーション「Codex Blanche」（Android 版、パッケージ名 `com.tamarilog.codexblanche`、以下「本アプリ」）における個人情報および関連データの取り扱いについて説明するものです。本アプリを利用することにより、ユーザーは本ポリシーに同意したものとみなされます。

## 1. 運営者

本アプリは主にオープンソース ソフトウェアとして [Tamari-log/Codex-Blanche-App](https://github.com/Tamari-log/Codex-Blanche-App) を通じて公開されます。ビルドの配布主体が異なる場合は、当該配布者のプライバシー情報もあわせてご確認ください。

## 2. 本アプリが扱うデータの概要

本アプリは、チャット履歴、設定、API キー（ユーザーが入力した場合）、オプションの Google アカウント連携に関するトークン等を **主に端末内**（アプリ内ストレージ / DataStore 等）で処理します。運営者が、本アプリ単体を通じて **ユーザーの端末外のサーバーへプロファイルを自動送信する機能はありません**（下記の第三者サービス送信は除く）。

## 3. 第三者の AI サービス（Gemini / OpenAI 等）

1. ユーザーがメッセージを送信すると、選択した AI プロバイダの API へ **会話内容、添付ファイルから抽出したテキスト等**が送信される場合があります。  
2. これらのデータの取り扱いは、**各プロバイダのプライバシーポリシーおよび利用規約**に従います。利用前に各事業者の文書を確認してください。  
3. API キーを本アプリに保存する場合、そのキーは **端末内**に保持され、AI プロバイダへの認証に使用されます。運営者がキーを受け取ることは通常ありません。

## 4. Google ドライブ連携（任意）

1. ユーザーが Drive 同期を有効にした場合、本アプリは Google の認証および Google Drive API を利用して、バックアップ JSON 等のファイルを読み書きする場合があります。  
2. この処理はユーザーの操作と OAuth の範囲内で行われ、Google の [プライバシーに関する方針](https://policies.google.com/privacy) 等が適用されます。

## 5. ネットワークとログ

1. 本アプリは、AI API および Drive API 等への通信のためにインターネット接続を使用します。  
2. OS や開発者向けデバッグビルドでは、追加のログが出力されることがあります。リリース運用ではユーザー自身のビルド設定に依存します。

## 6. 画像・文書などの添付

ユーザーが選択したファイルは、主に端末上で処理され、AI に送信するために加工される場合があります。**機微な個人情報や業務秘密**を含むファイルをアップロードする際は、各 AI プロバイダのデータ取り扱いを十分に確認してください。

## 7. 子どもの利用

本アプリは、子どもを対象としたサービスを意図していません。保護者の監督のもとでご利用ください。地域の法令で年齢制限がある場合は、それに従ってください。

## 8. セキュリティ

本アプリは一般的なモバイル開発の慣行に従って実装されますが、**インターネット上の通信や端末保管は完全に安全であるとは限りません**。API キーの共有や端末の紛失時のリスクについて、ユーザー自身の管理が重要です。

## 9. 本ポリシーの変更

運営者は本ポリシーを更新することがあります。更新後の内容は、本リポジトリ上の本ファイルの改訂により告知します。継続利用により、変更後のポリシーに同意したものとみなす場合があります。
